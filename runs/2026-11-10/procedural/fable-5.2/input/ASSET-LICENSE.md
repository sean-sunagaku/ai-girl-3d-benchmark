# Common base asset

MakeHuman hm08 base mesh. The source header explicitly releases the asset under CC0.

Pinned source: https://raw.githubusercontent.com/makehumancommunity/makehuman/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/makehuman/data/3dobjs/base.obj

The common upper-body.obj only crops the body, removes helper geometry, and converts coordinates to meters/Z-up. It does not sculpt a likeness. Each model must make the appearance, hair, clothing and scene itself.
