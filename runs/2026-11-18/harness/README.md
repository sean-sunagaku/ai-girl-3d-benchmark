## コスト（コーディネーター集計・推定）
前提: Codex 利用枠での実行で API の直接課金はないため、Codex が記録したトークン使用量を
API レートで換算した推定値を記録する。API 標準レート（100万トークンあたり、入力272K以下）は
Astra が入力 $8 / キャッシュ入力 $0.40 / 出力 $40、Sol が入力 $2 / キャッシュ入力 $0.10 / 出力 $10。
Fast は標準の2倍。Codex クレジット単価（100万トークンあたり）は Astra が 200 / 10 / 1,000、
Sol が 50 / 2.5 / 250。出力トークンには reasoning 分を含む（内訳は run.json）。

- GPT-6.2 Astra: 入力 17,756,547（うちキャッシュ 17,540,096、非キャッシュ 216,451）、出力 106,112
  → Fast 換算で約 $25.98（標準換算では約 $12.99）。Codex クレジット換算で約 325 credits。
- GPT-6.2 Sol: 入力 8,603,295（うちキャッシュ 8,414,592、非キャッシュ 188,703）、出力 93,196
  → Fast 換算で約 $4.30（標準換算では約 $2.15）。Codex クレジット換算で約 54 credits。
- 疎通テスト分（Astra 入力 27,247 / 出力 7、Sol 入力 31,360 / 出力 6）は含まない。
