# 実験条件と公開スナップショット

## 題材

1枚の写真から、Blenderで編集可能な、服を着た人物の上半身モデルを制作する課題です。正面の写真に写らない横顔や背面は各モデルによる推定です。人物の特定や3Dスキャンは行う課題ではありません。

入力の元写真、MakeHumanベース、上半身ベース、座標・ランドマーク情報を [共通入力](../benchmarks/cafe-selfie-v1/inputs) に収録しています。初回と追加版の指示は [prompts](../benchmarks/cafe-selfie-v1/prompts) に保存しています。

## 2段階

初回 `procedural` は写真由来の人物テクスチャを使わない条件でした。追加版 `photo-textured` は、各自の初回成果物から続け、写真の色やテクスチャを実際の立体形状に使うことを許可しました。どちらも平面写真だけで人物を代用したり、最終画像へ写真を合成することを禁止した課題です。

各段階の課題本文は共通です。Argonには通信障害からの復旧のため追加の継続指示が送られました。収録した `*-recovery.md` はその共通の継続指示で、全モデルの全送信履歴が同一という意味ではありません。各モデルの `PROMPT.md` と、公開側の共通指示を併せて参照してください。

## 環境と制約

- Blender 5.1.1、macOS、Apple M4 Max、メモリ36 GBで行った実験。
- Cursor CLIは2026.10.12-d47ca18、Claude Codeは2.1.296、Codex CLIは0.162.0-alpha.17.2という当時の記録。
- 追加版の指定はCycles CPU、3スレッド、32サンプル、デノイズあり。
- beautyは960×1040、正面・斜め・横・背面は各768×768を要求。
- 共通入力以外のモデルやテクスチャ、外部の画像・3D生成サービスの使用は禁止。
- 初回にはEEVEEを許可しつつGPU不使用と書いた矛盾がある。原文を後から修正していない。
- ハーネスや画像アクセスの方式、制作時間、再試行回数には違いがある。

## 公開するファイル

2026-10-15時点で存在する提出物を、そのままコピーしています。生成コード、.blend、素材、最終画像を修正したり、公開のために再レンダリング・再検証したりしていません。ファイル名に `verification` や `report` があるもの、各モデルのREADMEにある自己説明は元の制作時の記録であり、公開時の新しい検査・外見評価ではありません。

作業用ログ、認証設定、Pythonキャッシュ、`.blend1` バックアップは配布対象から外しています。最終シーン、追加版の参照用初回シーン、必要な素材はReleaseに収録しています。

外見の採点・順位付け・講評は作りません。人が元の写真、複数方向のPNG、Blenderシーンを見比べられるように公開しています。
